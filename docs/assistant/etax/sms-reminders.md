# Understand SMS reminders

eTax can send SMS reminders when a filing deadline is approaching and a filing period still needs attention.

## When reminders are useful

Reminders are meant for cases such as:

- Income records still need to be added or confirmed.
- The computation has not been reviewed.
- The filing hand-off has no acknowledgement reference yet.
- Filing is acknowledged, but payment is not confirmed.

## When no reminder is needed

If the filing acknowledgement and payment confirmation are both recorded, eTax treats the journey as complete and does not need to send a deadline action reminder.

## Reminder timing

The reminder window is configurable. Examples include 7 days, 5 days, 3 days, or 1 day before the due date.

## Message wording

Reminder messages should end with a clear instruction to return to the app. Example:

Please use the eTax app to complete filing and payment.

## Where to check related information

Use **Deadlines** to check due dates. Use **Filing tracker** to check the filing and payment status for a selected period.
